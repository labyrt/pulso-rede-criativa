# Contribuindo

1. Crie uma branch a partir de `main`.
2. Instale as dependências e execute `python manage.py test`.
3. Faça commits pequenos e descritivos.
4. Nunca adicione `.env`, banco local, arquivos de mídia ou credenciais.
5. Abra um Pull Request explicando mudança, impacto e validação.

Formato recomendado para branches: `feature/nome-da-mudanca`, `fix/nome-do-problema` ou `docs/nome-do-documento`.
